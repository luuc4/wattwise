# WattWise Branding Guide

## Brand Overview
WattWise is an intelligent energy management platform helping users save energy and costs through real-time monitoring and smart optimization.

---

## Color Palette

### Primary Colors
- **Primary Green**: `#00c389`
  - RGB: `0, 195, 137`
  - Usage: Main brand color, primary buttons, highlights, logo accent
  
- **Secondary Blue**: `#0073e6`
  - RGB: `0, 115, 230`
  - Usage: Secondary elements, gradients, call-to-action backgrounds

### Supporting Colors
- **Dark**: `#1e293b`
  - RGB: `30, 41, 59`
  - Usage: Text, headings, dark sections
  
- **Light**: `#f8f9fa`
  - RGB: `248, 249, 250`
  - Usage: Background, light sections
  
- **Accent Yellow**: `#ffc107`
  - RGB: `255, 193, 7`
  - Usage: Highlights, warnings, special badges

### Gradients
- **Primary Gradient**: `linear-gradient(135deg, #00c389 0%, #0073e6 100%)`
  - Usage: Hero sections, headers, premium elements

---

## Typography

### Font Family
**Poppins** (Google Fonts)
- Weights available: 300, 400, 500, 600, 700
- Link: `https://fonts.googleapis.com/css2?family=Poppins:wght@300;400;500;600;700&display=swap`

### Font Usage
- **Headlines (H1-H2)**: 
  - Font weight: 700 (Bold)
  - Usage: Main page titles, section headers
  
- **Subheadings (H3-H5)**: 
  - Font weight: 600 (Semi-Bold)
  - Usage: Feature titles, card headers
  
- **Body Text**: 
  - Font weight: 400 (Regular)
  - Usage: Paragraph text, descriptions
  
- **Light Text**: 
  - Font weight: 300 (Light)
  - Usage: Subtle text, secondary information
  
- **Button Text**: 
  - Font weight: 500 (Medium)
  - Usage: CTA buttons, navigation items

## Logo

### Logo Components
- **Icon**: Lightning bolt (⚡) - `<i class="fas fa-bolt"></i>`
  - Color: Primary Green (#00c389)
  
- **Text**: "Watt**Wise**"
  - Font: Poppins, Weight: 700
  - "Watt" in black/dark
  - "Wise" in Primary Green (#00c389)

### Logo Usage
```html
<i class="fas fa-bolt me-2" style="color: #00c389;"></i>
<span style="font-weight: 700;">Watt<span style="color: #00c389;">Wise</span></span>
```

---

## Design Principles
1. **Modern & Clean**: Minimalist design with plenty of white space
2. **Friendly & Approachable**: Rounded corners, soft shadows
3. **Tech-Forward**: Gradient backgrounds, modern iconography
4. **Trust & Reliability**: Professional color palette, clear typography
5. **Eco-Conscious**: Green primary color reflects sustainability
